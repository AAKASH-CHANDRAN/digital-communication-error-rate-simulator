## 📡 About the Project

The **Digital Communication Error Rate Simulator** is a web-based ECE mini project that demonstrates how channel noise affects digital data transmission and Bit Error Rate (BER).

Users can generate binary data, simulate a noisy communication channel, compare transmitted and received bits, and analyze communication performance.

## ✨ Features

- 🔢 Adjustable number of transmitted bits (8–1000)
- 📡 Adjustable channel noise level (0%–50%)
- 📤 Display of transmitted bits
- 📥 Display of received bits
- 🔴 Highlighting of incorrect bits
- 📊 Calculation of total bits, bit errors, correct bits, and BER
- 📈 BER vs Channel Noise graph
- 🔄 Reset option
- 🎲 Seeded random-number generation for reproducible results
- 📉 Graph using an average of 100 trials at each noise level

## ⚙️ How It Works

1. **Bit Generation:** Generates a sequence of binary bits (0s and 1s).
2. **Transmission:** Sends the generated bits through a simulated channel.
3. **Channel Noise:** Randomly flips bits according to the selected noise probability.
4. **Reception:** Displays the received bit sequence.
5. **Error Detection:** Compares transmitted and received bits.
6. **BER Calculation:** Calculates bit errors and measured BER.
7. **Graph Generation:** Displays average measured BER at noise levels from 0% to 50%, in 5% increments, using 100 trials per level.



## 📐 Formulas

**1. Bit Error Rate (BER)**

BER = Number of Bit Errors ÷ Total Bits Transmitted

**2. Bit Error Rate Percentage**

BER (%) = BER × 100

**3. Correct Bits**

Correct Bits = Total Bits Transmitted − Number of Bit Errors

## 📊 Expected Results

- At **0% channel noise**, no bit flips occur.
- As channel noise increases, the probability of bit errors generally increases.
- Incorrectly received bits are highlighted in red.
- The graph illustrates the relationship between channel noise and measured BER.

Measured BER may differ from the selected noise percentage because simulations use finite numbers of bits and random trials.

## 🎓 Applications

- Understanding digital communication systems

## 🚧 Limitations

This project uses a simplified binary bit-flip model. It does not simulate a complete radio-frequency communication system or detailed analog channel effects.
